# smartcost

تطبيق مستقل لإدارة المصروفات والدخل الشهري والشهادات البنكية.

## الحالة
هذا المستودع يبدأ فصل البرنامج المالي عن SMART-TIME. الهيكل الأولي هنا يثبت حدود التطبيق وعقد الـ API وقاعدة البيانات؛ نقل واجهة المصروفات الأصلية ومكوناتها واختبار تكافؤ السلوك ما زال مطلوبًا قبل اعتبار الفصل مكتملًا أو النشر.

## النطاق
- المصروفات، بما فيها مصروفات التعليم والمركبات كتصنيفات داخل المصروفات.
- الدخل الشهري والشهادات البنكية.
- تصدير/استيراد نسخة احتياطية مالية فقط.
- لا يتضمن المحفظة أو تطبيق المركبات المستقل أو التعليم المستقل أو الذكاء الاصطناعي أو بقية برامج SMART-TIME.

## التشغيل
1. انسخ `.env.example` إلى `.env` واضبط القيم المناسبة.
2. `npm install`
3. `npm run dev`

لا تضع أسرارًا أو بيانات مالية حقيقية في GitHub. راجع [عقد API](docs/API.md) و[الشاشات](docs/SCREENS.md).

## التحقق
لم يتم تشغيل build أو اختبارات runtime في بيئة هذا المستودع حتى الآن. لا تعتبر النسخة جاهزة للإنتاج قبل نقل واجهة المصدر، وإضافة اختبارات CRUD والنسخ الاحتياطي، ثم تشغيلها فعليًا.
