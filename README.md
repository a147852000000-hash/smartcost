# smartcost

تطبيق مستقل لإدارة المصروفات والدخل الشهري والشهادات البنكية، منفصل عن مستودع SMART-TIME الأصلي.

## النطاق المالي
- واجهة المصروفات الأصلية وأقسام المنزل والطب والعمل والشخصي والمركبات والتعليم.
- الدخل الشهري والشهادات البنكية وتقارير المال.
- SQLite API مستقل ونسخ احتياطي/استعادة للمصروفات والدخل الشهري ودخل المركبات والشهادات فقط.
- لا يتضمن المحفظة أو التعليم كتطبيق مستقل أو إدارة المركبات كتطبيق مستقل أو AI أو الخزنة أو الرحلات أو الدردشة أو الميزات الدينية أو الميديا أو الرياضة.

## التشغيل المحلي
1. انسخ `.env.example` إلى `.env`.
2. `npm install`
3. `npm run dev`
4. افتح `http://127.0.0.1:5173`.
5. شغّل `npm test` لاختبارات API، و`npm run build` للتحقق من البناء.

## الأمان والجاهزية
**هذه النسخة ليست جاهزة للنشر العام.** لا تزال المصادقة وعزل بيانات المستخدمين غير مطبقين. الـ API يعطّل عمليات البيانات تلقائيًا عندما تكون `NODE_ENV=production` إلى أن تكتمل المصادقة. لا تفعّلها أو تعرض الـ API للإنترنت قبل تنفيذ المصادقة والتفويض وحدود الملكية والتحقق الأمني.

## حالة النقل
نُقلت مكونات واجهة المال الأصلية إلى هذا المستودع مع تقليل أنواع البيانات والخدمات المشتركة. لم يتم تشغيل build أو اختبارات API في بيئة تنفيذ مستقلة بعد؛ لذلك لا توجد نتيجة نجاح اختبار مؤكدة. يجب التحقق من CRUD والنسخ الاحتياطي والاستعادة ثم إصلاح أي أخطاء بناء قبل اعتبار الفصل مكتملًا.

لا توجد أسرار فعلية في المستودع. بيانات البيئة النموذجية في `.env.example` فقط.
