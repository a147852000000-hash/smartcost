# Screens and feature boundaries

## Screens to preserve from SMART-TIME
- Expenses: personal, household, work, vehicle, and education expenses.
- Monthly income.
- Bank certificates.
- Financial reports and export/print.

## Remove from this app
- Main multi-product dashboard and live ticker.
- Separate education app/screen (education expenses remain a category).
- Standalone vehicles management and wallet.
- AI, notes, calculator, trips, chat, religious features, vault, media, sports, and calendar.

## UI migration status
The original `ExpensesView.tsx`, `src/components/expenses/*`, and `IncomeCertificatesView.tsx` have not yet been ported into this repository. This document defines the migration boundary; it does not claim UI parity.
